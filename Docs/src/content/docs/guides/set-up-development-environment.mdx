This guide sets up Alexandria's development environment: Docker Compose runs the infrastructure services (PostgreSQL, Garage, RabbitMQ, Nginx), and a tmux session orchestrates all backend processes and the frontend dev server with hot reload.

<Aside type="tip">
  **TL;DR**: Generate dev TLS certs → fill `.env` → `docker compose -f docker-compose.dev.yml up -d` → `./init-garage.sh` → configure `appsettings.Development.json` per backend project → `pnpm install` in `Frontend/` → `./run-dev.sh`.
</Aside>

## Prerequisites

- **Docker** with **Docker Compose** (v2)
- **tmux** — the launcher script orchestrates all processes inside it
- **.NET 10 SDK** — backend
- **Node.js 20+** and **pnpm 10+** — frontend
- **AWS CLI** (optional) — used by `init-rustfs.sh` when running RustFS, and for the S3 connectivity check under Troubleshooting
- **openssl** — for generating the dev TLS certificates

## What Runs Where

**Docker Compose** (`docker-compose.dev.yml`) manages the stateful side:

| Service | Purpose | Host port |
|---|---|---|
| `postgres` | PostgreSQL 16, db `alexandria_dev`, user `alexandria_user` | 5432 |
| `garage` | S3-compatible storage (S3 API on 9000, admin API on 9001) | 9000 / 9001 |
| `rabbitmq` | Message broker + management UI | 5672 / 15672 |
| `rabbitmq-config` | One-shot: renders queue definitions from template | — |
| `nginx` | TLS termination, `/api/` proxy, authenticated `/stream/` + preview gating (host network) | 8080 → 8443 |
| `essentia-effnet-worker` | Python genre/mood classification (waits for messages) | — |
| `essentia-maest-worker` | Python genre classification (waits for messages) | — |

**tmux** (created by `run-dev.sh`) hosts 7 windows:

| # | Window | Command |
|---|---|---|
| 0 | Frontend | Vite dev server (`pnpm dev`, port 5173) |
| 1 | API | ASP.NET Core on http://0.0.0.0:5000 |
| 2 | DocumentWorker | Preview generation worker |
| 3 | MediaWorker | Thumbnails/metadata/preview clips worker |
| 4 | TranspilationWorker | DASH/HLS transcoding worker |
| 5 | MediaMetadataWorker | Enrichment orchestrator |
| 6 | LyricsWorker | Lyrics fetching worker |

## Setup Steps

<Steps>

1. **Clone the repository**

   ```bash
   git clone https://github.com/SpasMilenkov/Project-Alexandria.git
   cd Project-Alexandria
   ```

2. **Generate the dev TLS certificate**

   The dev Nginx terminates HTTPS on port 8443 and expects certs in `nginx/certs/` (gitignored):

   ```bash
   mkdir -p nginx/certs
   openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
     -keyout nginx/certs/self-signed.key \
     -out nginx/certs/self-signed.crt \
     -subj "/CN=localhost" \
     -addext "subjectAltName=DNS:localhost,IP:127.0.0.1"
   ```

3. **Configure environment variables**

   ```bash
   cp .env.template .env
   ```

   Four values are **required** (Compose refuses to start without them); everything else has dev defaults:

   ```ini title=".env"
   RABBITMQ_USER=alexandria          # required
   RABBITMQ_PASSWORD=...             # required
   API_RABBITMQ_USER=api_user        # required
   API_RABBITMQ_PASSWORD=...         # required

   DB_PASSWORD=dev_password_123      # optional, has default
   # Per-worker RabbitMQ passwords also have dev defaults
   ```

4. **Start the infrastructure**

   ```bash
   docker compose -f docker-compose.dev.yml up -d
   docker compose -f docker-compose.dev.yml ps
   ```

   Wait until `postgres`, `garage`, and `rabbitmq` report healthy. The two Essentia workers will start too — they idle until the pipeline sends them work.

5. **Initialize Garage**

   ```bash
   ./init-garage.sh
   ```

   This creates the layout and five buckets (`alexandria-files`, `alexandria-previews`, `alexandria-temp`, `alexandria-images`, `alexandria-streaming`), three access keys (`alexandria-master-key`, `alexandria-preview-key`, `alexandria-streaming-key`), website-mode endpoints for streaming/previews, and CORS on the images bucket.

   Copy the printed key IDs/secrets into your `appsettings.Development.json` (next step). To retrieve them later:

   ```bash
   docker exec alexandria-garage-dev /garage key info alexandria-master-key
   ```

6. **Configure the backend projects**

   Each backend project reads its own gitignored `appsettings.Development.json`. Create one next to each `appsettings.Template.json` (API + 5 workers). The API example below is verified against the real config shape; workers need the same `ConnectionStrings` / `S3Storage` / `RabbitMQ` blocks but not `Jwt` / `Csrf` / `Admin`:

   ```json title="Backend/Alexandria.Api/appsettings.Development.json"
   {
     "Serilog": { "MinimumLevel": { "Default": "Information" } },
     "ConnectionStrings": {
       "AlexandriaPostgres": "Host=localhost; Port=5432; Database=alexandria_dev; Username=alexandria_user; Password=dev_password_123"
     },
     "Encryption": {
       "IterationCount": 600000
     },
     "Features": {
       "Autotagging": true
     },
     "S3Storage": {
       "Provider": "Garage",
       "Endpoint": "http://localhost:9000",
       "PublicEndpoint": "https://localhost:8443/",
       "UseHttps": false,
       "AccessKey": "<from init-garage.sh>",
       "SecretKey": "<from init-garage.sh>",
       "Region": "garage",
       "UploadBucket": "alexandria-files",
       "PreviewBucket": "alexandria-previews",
       "TempBucket": "alexandria-temp",
       "ImagesBucket": "alexandria-images",
       "ProviderSettings": {
         "Garage": {
           "Region": "garage",
           "ForcePathStyle": true,
           "MetricsUrl": "http://localhost:9001/metrics",
           "MetricsToken": ""
         }
       }
     },
     "RabbitMQ": {
       "HostName": "localhost",
       "Port": 5672,
       "UserName": "api_user",
       "Password": "<API_RABBITMQ_PASSWORD from .env>",
       "VirtualHost": "alexandria"
     },
     "Admin": {
       "Email": "admin@alexandria.local",
       "Password": "<seed admin password>",
       "Name": "SystemAdministrator"
     },
     "Jwt": {
       "Secret": "<openssl rand -base64 64>",
       "Issuer": "Alexandria.Dev",
       "Audience": "Alexandria.Dev.Users",
       "AccessTokenExpiryMinutes": 15,
       "RefreshTokenExpiryDays": 7
     },
     "Csrf": {
       "SecretKey": "<openssl rand -base64 32>",
       "ExpiryMinutes": 60
     },
     "Cors": {
       "AllowedOrigins": ["https://localhost:8443", "http://localhost:5173"]
     }
   }
   ```

   <Aside type="caution">
     Copy this file to **all five worker projects** as well, removing the `Jwt`,
     `Csrf`, and `Admin` sections:
     `Backend/Alexandria.Workers.Document`, `Backend/Alexandria.Workers.Media`,
     `Backend/Alexandria.Workers.MediaTranspilation`,
     `Backend/Alexandria.Workers.MediaMetadata`, `Backend/Alexandria.Workers.Lyrics`
   </Aside>

   Workers also carry a top-level `Urls` key binding their health endpoint — keep the defaults when copying (`Document` 5001, `Media` 5002, `Transpilation` 5003, `MediaMetadata` 5005, `Lyrics` 5006) so the ports don't collide with the API.

7. **Install frontend dependencies**

   ```bash
   cd Frontend && pnpm install && cd ..
   ```

8. **Start the development servers**

   ```bash
   ./run-dev.sh --s3-provider Garage
   ```

   The script pre-builds all six backend projects, then launches the 7-window tmux session described above and attaches to it.

</Steps>

## Tmux Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+b` then `w` | Interactive window list |
| `Ctrl+b` then `0-6` | Jump to window (see table above) |
| `Ctrl+b` then `d` | Detach (services keep running) |
| `tmux attach -t dev-session` | Reattach |
| `Ctrl+c` in a window | Stop that service |

Stop everything with:

```bash
tmux kill-session -t dev-session
docker compose -f docker-compose.dev.yml down
```

### The `--no-analyzers` Flag

```bash
./run-dev.sh --s3-provider Garage --no-analyzers
```

Skips Roslyn analyzers during the pre-build (`-p:RunAnalyzersDuringBuild=false`). Useful for faster iteration on weaker machines; leave analyzers on when you want build-time diagnostics enforced.

### S3 Provider Note

The launcher accepts `Garage | RustFS` (it maps to per-project launch profiles like `API (Garage)`), but **only Garage is wired into `docker-compose.dev.yml`**. Selecting RustFS assumes you run that storage yourself and point `S3Storage:Endpoint` at it.

## Accessing Services

| Service | URL | Credentials |
|---------|-----|-------------|
| Frontend (via Nginx, full stack) | https://localhost:8443 | Accept self-signed cert |
| Frontend (Vite direct) | http://localhost:5173 | — |
| API | http://localhost:5000 | JWT after login |
| RabbitMQ Management | http://localhost:15672 | From `.env` |
| Garage S3 / Admin | http://localhost:9000 / :9001 | Keys from `init-garage.sh` |
| PostgreSQL | localhost:5432 | `alexandria_user` / from `.env` |

## Troubleshooting

### Compose refuses to start

Missing required env vars — set all four `RABBITMQ_*`/`API_RABBITMQ_*` values in `.env` (step 3). Check what's missing with `docker compose -f docker-compose.dev.yml config`.

### Nginx exits immediately

The certs from step 2 are missing or unreadable. Re-run the openssl command and restart the container.

### Database migrations not applied

```bash
cd Backend
dotnet ef database update --project Alexandria.Data --startup-project Alexandria.Api
```

(The API also auto-applies migrations on startup unless disabled.)

### S3 connection errors

Verify credentials match across three places: `.env` (broker), `init-garage.sh` output (bucket keys), and every `appsettings.Development.json`. Test connectivity:

```bash
AWS_ACCESS_KEY_ID=YOUR_ACCESS_KEY AWS_SECRET_ACCESS_KEY=YOUR_SECRET_KEY AWS_DEFAULT_REGION=garage \
  aws --endpoint-url http://localhost:9000 s3 ls
```

### "Address already in use"

```bash
lsof -i :5000  # API
lsof -i :5173  # Vite
lsof -i :8443  # Nginx
lsof -i :5432  # PostgreSQL
lsof -i :9000  # Garage S3
```
