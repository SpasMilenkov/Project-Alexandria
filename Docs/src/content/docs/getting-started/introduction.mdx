Alexandria is a **self-hosted, all-in-one personal library** for your files and media. It runs on your own hardware (a home server, an old PC, a NAS box behind Docker) and gives you a private web interface for everything you store: documents, photos, notes, archives, music, video.

<Aside type="caution">
  Alexandria is <strong>pre-alpha software</strong>. Do not store files you care about without your own backups. Data loss, breaking changes, and instability are expected at this stage.
</Aside>

## Who It's For

Alexandria is built for personal use on **private networks**: "my files, on my hardware, reachable from my devices". It is not designed for commercial use or for exposing directly to the internet.

## Under the Hood

A Vue single-page app talks to an API that coordinates background workers through a message queue. Files live in S3-compatible object storage; state lives in PostgreSQL. Everything ships as Docker containers.

Curious about internals? The [Development](/development/architecture/) section covers the architecture in depth, but you don't need any of it to run or use Alexandria.

## Requirements

| | Minimum | Comfortable |
|---|---|---|
| CPU | 2 cores | 4 cores (media features) |
| RAM | ~2 GB base stack | 4 GB with media processing + monitoring |
| Disk | 10 GB for the stack | + as much as your library needs |
| Software | Docker + Docker Compose v2 | |

Optional features scale requirements: media workers add ~1 GB RAM, monitoring adds ~512 MB.
